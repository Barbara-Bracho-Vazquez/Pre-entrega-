Descripción:
Este proyecto consiste en una página web básica desarrollada con HTML y CSS. El sitio muestra productos con sus imágenes, nombres y precios, cuenta con una página de inicio y una página de contacto navegables entre sí, y presenta un diseño completamente responsivo.

Contiene:

- Estructura básica de HTML con etiquetas semánticas principales: header,nav,main, section, footer.
- Formulario de contacto.
- Estilos básicos aplicados con CSS.
- Diseño responsivo con Flexbox.
- Contenido multimedia y navegación interna.

Tecnologías utilizadas:
HTML y CSS

Estructura General del Proyecto:
Menú principal
 ├── Visualización de productos
 ├── Botón de carrito
 ├── Barra de navegación (Inicio / Contacto)
 └── Formulario de contacto
  

Ejecución del programa:
Abrir el archivo index.html desde el navegador o desde la terminal de Visual Studio Code con Live Server.
